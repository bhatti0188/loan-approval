# Loan Approval Prediction

## 📌 Project Overview

This project uses **Machine Learning** to predict whether a loan application will be **Approved or Rejected**.

The project uses **Logistic Regression** as the main machine learning model.

## 🎯 Objective

The main goal of this project is to:

* Analyze the loan approval dataset
* Clean and preprocess the data
* Handle missing values and categorical data
* Perform data analysis and visualization
* Train a Logistic Regression model
* Predict loan approval status
* Evaluate the model performance

## 📊 Dataset

The dataset contains information about loan applicants, such as:

* Gender
* Married
* Dependents
* Education
* Self Employed
* Applicant Income
* Coapplicant Income
* Loan Amount
* Loan Amount Term
* Credit History
* Property Area

### Target Variable

**Loan_Status**

* `Y` → Loan Approved
* `N` → Loan Rejected

## 🤖 Machine Learning Model

### Logistic Regression

Logistic Regression is used because the target variable has two possible outcomes:

* Approved
* Rejected

The model predicts the probability of loan approval based on the applicant's information.

## 📈 Model Evaluation

The model is evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
* ROC-AUC
